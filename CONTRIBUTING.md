# Contributing / Contribuindo

PRs and issues are welcome. / PRs e issues são bem-vindos.

**Never commit real personal data** (résumés, `profile_truth.md`, outputs, `.env`).
`input/`, `data/` and `outputs/` are git-ignored; use `examples/jane_doe/` for fixtures.
**Nunca versione dados pessoais reais.** Use apenas dados fictícios em `examples/`.

Run the tests before opening a PR: `python -m unittest discover -s tests -v`
